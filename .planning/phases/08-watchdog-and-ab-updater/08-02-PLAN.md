<objective>
Turn rmm-watchdog into the supervisor and updater: it runs the active slot's agent, restarts it within 10 s, independently verifies and applies pending releases into the inactive slot, and rolls back builds that fail the health check.

Purpose: The watchdog is the part that must survive a bad agent build; it has no network and trusts only the compiled root keys.

Implement Supervisor on std threads and std::process. Start the active slot's binary (bootstrap when active is 'bootstrap') with the agent args and env RMM_AGENT_STATE_DIR; restart on exit with backoff 1,2,4,8 s (reset after 60 s up). Every 5 s: check_pending; on Staged, stop the child (terminate, then kill after 10 s), install, start the new slot as a trial. During a trial: healthy when <state_dir>/health.json shows the trial version and the running pid before health_timeout → promote (previous = old slot, floor = release seq, trial = null); otherwise, or after 3 crashes in the trial → stop it, switch back to previous, add the hash to bad_hashes, save, restart previous. Log every transition as one JSON line on stderr. Tests (unix, with small shell-script 'agents' in a temp root and a 3 s health timeout): a killed child restarts within 2 s at the first backoff; a healthy trial is promoted; a trial that never writes health rolls back within the timeout and its hash is never retried; a crash-looping trial rolls back after 3 crashes.
