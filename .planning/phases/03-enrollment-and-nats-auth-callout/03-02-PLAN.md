- SMBIOS UUID bytes 0-3, 4-5, 6-7 are little-endian for SMBIOS >= 2.6 and must be byte-swapped when formatting; for 2.5 and older they are printed as stored

- Missing /sys/class/dmi/id files (containers) -> None fields, weak fingerprint
- KeyStore::load on a missing file returns Ok(None); on a corrupted DPAPI blob returns an error, never a new key
- Unix keystore refuses to load a key file whose mode allows group or other access
